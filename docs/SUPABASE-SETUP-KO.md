# PC CLUB 1.1 · Supabase 최초 설정

프로젝트 주소: https://gtvgeqdxcoiplhhufvgg.supabase.co
관리자 웹: https://minchan012309-spec.github.io/kiosk/#/admin
키오스크 웹: https://minchan012309-spec.github.io/kiosk/#/kiosk

이 버전은 로컬 서버를 실행하지 않습니다. 관리 콘솔 EXE·키오스크·각 PC 런처·폰이 모두 Supabase에 연결됩니다. 설치 파일에 Node.js가 포함돼 있으므로 별도 개발 도구를 설치하지 않습니다. 인터넷 연결이 필요합니다.

## 1. SQL 설치

Supabase Dashboard에서 프로젝트를 선택한 뒤 SQL Editor → New query를 엽니다.

1. `001_club.sql` 전체를 붙여 넣고 실행합니다. 테이블, 권한, 안전한 RPC, Realtime 알림, 로고 저장소가 생성됩니다.
2. Authentication → Users → Add user에서 **최고 관리자용 이메일과 비밀번호**를 직접 생성합니다. 이메일 확인(Auto confirm)을 완료 상태로 설정합니다. 비밀번호는 채팅이나 코드에 적지 마세요.
3. `002_first_owner.sql`에서 `YOUR_OWNER_EMAIL@example.com`을 방금 생성한 이메일로 바꾼 뒤 실행합니다. 이 계정이 모든 권한을 가진 소유자가 됩니다.

제공한 publishable 키만으로는 DB 설치나 관리자 생성 권한을 얻지 못합니다. 최초 소유자는 위 순서로 명시적으로 등록해야 합니다. 회원가입만 한 계정에는 운영 권한이 없습니다. 기존 SQLite 데이터는 자동 이전하지 않습니다.

## 2. 계정 생성용 Edge Function 배포

프로젝트 → Edge Functions → Deploy a new function → Via Editor를 엽니다.

- 함수 이름: **club-admin**
- `club-admin.ts` 내용을 편집기의 `index.ts`에 붙여 넣습니다.
- 함수 설정의 **Verify JWT**는 끕니다. 이 함수는 코드 안에서 Supabase Auth.getUser로 JWT를 직접 검증하고, 활성 소유자 계정인지 확인합니다. 공개 함수가 무조건 계정을 생성하도록 허용하는 것이 아닙니다.
- Deploy를 누릅니다.

`SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`는 Supabase Edge Function의 기본 서버 환경을 사용합니다. service_role 키를 웹·런처·GitHub 코드나 채팅에 입력하지 마세요.

CLI를 쓰는 경우 저장소의 `supabase` 폴더에서 제공되는 설정으로 배포할 수 있습니다:

```sh
supabase functions deploy club-admin --project-ref gtvgeqdxcoiplhhufvgg --no-verify-jwt
```

함수를 아직 배포하지 않아도 최초 소유자 로그인과 기본 운영은 가능하지만, 관리자 화면에서 다른 계정을 생성하거나 비밀번호를 재설정하는 기능은 동작하지 않습니다.

## 3. 설치 및 운영 설정

1. 운영 노트북에는 **PC Club Admin**, 사용자 노트북에는 **PC Club Station**을 설치합니다. 기존 1.0 프로그램을 모두 종료한 뒤 새 버전을 설치하세요. 이전 로컬 서버 EXE는 더 이상 필요하지 않습니다.
2. 관리 콘솔 또는 관리자 웹에서 소유자 이메일·비밀번호로 로그인합니다.
3. 좌석 / PC에서 좌석 번호를 추가하고, PC 등록 코드를 발급합니다. 각 Station에서 해당 코드를 한 번 입력합니다. 로컬 서버 연결 파일은 사용하지 않습니다.
4. 등록 때 표시되는 **기기별 비상 종료 코드**는 운영자가 안전하게 보관합니다. 인터넷 장애 시 앱 종료에 사용합니다.
5. 좌석 / PC에서 **키오스크 연결 코드**를 발급하고 키오스크 화면에 입력합니다. 이 과정은 각 키오스크 브라우저에서 한 번만 필요합니다. 공개 URL이나 publishable 키만 아는 사람이 임의로 좌석을 배정하지 못하도록 보호합니다.
6. 상품 / 시간에서 간식·가격·재고·연장 상품을 설정합니다. 운영 설정에서 초기 시간과 머니를 정합니다.
7. 종료 비밀번호 화면에서 현장 종료 승인 비밀번호를 여러 개 등록합니다. 관리자 계정 로그인 비밀번호와는 별개입니다.

## 4. 게임 실행 파일 선택

게임은 각 사용자 노트북에 먼저 설치해야 합니다. 설치 파일에 게임 자체는 포함되지 않습니다.

- 관리자 웹의 게임 관리에서 이름·설명을 등록합니다. 모든 PC의 경로가 같으면 기본 실행 파일 경로를 입력할 수 있습니다.
- 각 Station의 대기/로그인 화면에서 운영자 메뉴 → **이 PC 게임 경로 설정**을 엽니다.
- 게임 설정 권한이 있는 관리자 이메일·계정 비밀번호로 잠금을 해제합니다.
- 게임별 **이 PC 실행 파일 선택**으로 실제 `.exe` 파일을 선택합니다. 이 PC의 선택 경로가 공통 경로보다 우선합니다.
- 설정 권한은 5분 후 자동 잠깁니다. `.lnk` 바로가기 대신 게임의 실행 파일을 고르세요.

기존 오류는 실행 전에 경로 형식/파일 존재 확인에서 발생한 것입니다. 다른 PC의 경로, 따옴표가 섞인 경로, 아직 설치하지 않은 게임은 실행할 수 없습니다. 새 버전은 환경 변수·따옴표·UNC 경로를 정규화하고 실제 찾으려던 경로를 표시합니다. 실제 행사 노트북의 게임·안티치트·독점 전체 화면 호환성은 별도 확인이 필요합니다.

## 5. 학생 이용 흐름

대기 중 PC는 전용 대기 화면을 표시합니다.

1. 키오스크에서 빈자리를 선택합니다.
2. 이름·학번과 **숫자 4~6자리 비밀번호**를 등록합니다. 비밀번호를 한 번 더 입력해 확인합니다. 서버에는 해시만 저장합니다.
3. 해당 PC에 로그인 화면이 자동으로 표시됩니다. 보통 다음 상태 수신 주기인 약 3초 안에 반영됩니다.
4. 방금 만든 비밀번호를 입력하고 **입장하기**를 누른 순간부터 시간이 차감됩니다.
5. 화면 오른쪽 위에 마우스를 약 1초 두면 게임 중 메뉴가 열립니다. 주문·연장 확인은 Windows 기본 확인창 대신 프로그램 안 팝업으로 표시합니다.
6. 시간 종료 또는 관리자 킥 시 실행한 게임을 닫고 **이용해 주셔서 감사합니다** 잠금 화면을 표시합니다. 약 8초 후 기본 대기 화면으로 돌아갑니다.

Alt+F4는 등록된 Station에서 차단하고 관리자에게 종료 시도/승인 요청을 보냅니다. 연결이 끊겨 있으면 재연결 후 알림을 보냅니다. 관리자 웹에서 PC 번호와 알림을 확인하고 승인·거절합니다. 프로그램이 닫힌 동안이나 Windows 시스템 화면까지 잠그는 OS 키오스크 기능은 아닙니다. 전역 단축키 등록에 실패하면 프로그램에 오류를 표시합니다.

## 6. 관리자 계정·권한과 폰

소유자는 관리자 / 권한에서 여러 계정을 생성하고 권한을 지정합니다. 계정마다 별도 비밀번호를 가집니다. 소유자는 모든 권한을 가지며 마지막 소유자는 비활성화할 수 없습니다.

권한은 현황 보기, 인적사항 보기, 시간 조정, 머니 조정, 이용 종료/킥, Windows 종료, 종료 승인, 주문·환불, 상품 관리, 게임 관리, 좌석 등록, 설정, 감사 기록, 개인정보 삭제로 구분합니다. 계정 관리는 소유자에게만 허용합니다. DB에서도 권한을 검사합니다.

폰에서는 관리자 웹 주소를 열어 로그인하세요. 모바일 화면에서 좌석·시간·머니·주문·종료 시도를 보고 권한에 따라 조작할 수 있습니다. 브라우저를 닫아 둔 상태의 OS 푸시 알림은 이 버전에 포함되지 않으며 관리자 화면을 열어 둔 동안 상태가 갱신됩니다.

브랜드 / 테마에서 서비스 이름·부제·로고·기본 모드를 변경합니다. 로고는 PNG/JPG/WebP 2MB 이하입니다. 각 기기는 라이트·다크·자동 모드를 따로 선택할 수 있습니다. 둥근모꼴을 제목·본문·숫자에 주로 사용하고 양진체는 서비스 이름에만 사용합니다.

## 준비 상태

이번 변경은 전체 테스트나 브라우저 점검을 반복하지 않고 컴파일·배포에 필요한 빌드만 수행합니다. SQL과 Edge Function은 이 환경에서 사용자의 Supabase 프로젝트에 적용하지 않았습니다. 위 설치 단계를 완료하기 전에는 클라우드 운영 준비가 끝난 것이 아닙니다. Windows 게임 실행·오버레이·단축키 차단·종료의 실제 동작은 행사 노트북에서 확인해야 합니다. 설치 파일은 미서명입니다.

웹 주소가 열리지 않으면 GitHub 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정한 뒤 Pages 게시 작업을 다시 실행하세요. SQL 설치 전에는 앱이 설치 안내/권한 오류를 표시합니다.
