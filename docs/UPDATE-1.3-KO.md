# PC CLUB 1.3 · 입장권(QR/바코드) 업데이트

1. Supabase SQL Editor에서 `004_tickets.sql`을 한 번 실행하세요. (001·003이 먼저 적용돼 있어야 합니다. 기존 데이터는 유지됩니다.)
2. 모든 Station / Admin을 1.3으로 업데이트하세요.

## 운영 흐름
1. **관리자 → 입장권 / 코인**에서 장수를 입력해 8자리 입장권을 만들고 `SVG 다운로드`로 QR·바코드(배경 투명, 흰색 코드) ZIP을 받아 인쇄합니다.
2. **입구 키오스크**: 이름·학번 입력 → 운영자가 준 입장권 번호 입력(바코드 스캐너 가능) → 기본 PC 시간·코인 지급.
3. **PC**: 빈 PC에서 입장권 번호를 입력하면 바로 시간이 시작됩니다. 코인으로 시간 연장·간식 주문. 시간이 남은 채 종료하면 남은 시간이 입장권에 저장되고, 시간이 없으면 로그인 화면에서 코인으로 충전 후 입장할 수 있습니다.
4. **피지컬 부스**: 관리자 폰에서 `📷 QR 스캔` → 코인 지급(+1/+3/… 또는 직접 입력, 부스 이름 기록).
5. **환전소·반납함**: 스캔 → 남은 코인으로 간식 교환 → `반납 · 초기화`. 개인정보·코인·시간이 지워지고 같은 입장권을 다시 쓸 수 있습니다.

새 권한: 입장권 생성·삭제·다운로드 / 발급 / 코인 지급 / 환전·반납. staff 기본 권한에 발급·코인 지급·환전·반납이 포함됩니다. 화면의 "머니"는 "코인"으로 바뀌었습니다.
