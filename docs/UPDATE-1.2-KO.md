# PC Club 1.2 업데이트

## 기존 사용자는 먼저 SQL 한 파일 적용

Supabase SQL Editor에서 `003_layout_media_restart.sql` 전체를 한 번 실행하세요. 기존 좌석·상품·게임·계정·이용 기록을 초기화하지 않습니다. 새 이미지 저장소와 좌석 편집/재부팅 API를 추가하고 서버 기본 테마를 다크로 바꿉니다. 브라우저에서 사용자가 직접 선택해 둔 테마는 유지됩니다.

최초 설치자는 최신 `001_club.sql`에 이 기능이 포함돼 있으므로 기존과 같이 001 → Auth 사용자 생성 → 002 최초 소유자 → Edge Function 순서로 설정하면 됩니다. 003은 001을 실행한 기존 프로젝트용입니다. Edge Function 코드는 이번 변경으로 재배포할 필요 없습니다.

## 프로그램 교체

기존 Station/Admin 프로그램을 승인 절차에 따라 완전히 종료한 뒤 새 설치형을 설치하거나 새 무설치 ZIP 전체를 별도 폴더에 풀어 실행합니다. 같은 Windows 계정의 PC 등록·게임 경로는 유지됩니다. Shell Launcher를 사용한다면 등록된 사본도 업데이트하세요.

## 변경점

- 종료할 때 반복 타이머·Windows 키 보호 보조 프로세스를 정리하고 닫힌 창을 다시 사용하지 않도록 수정했습니다.
- Windows 전용 저수준 키보드 훅으로 Alt+F4를 차단합니다. 다른 앱과 전역 단축키 등록을 경쟁하는 방식 대신 전용 보조 EXE를 사용합니다. 보조 EXE는 설치형/무설치형에 함께 포함됩니다. 런처 종료 시 정리되며 런처가 비정상 종료돼도 부모 프로세스 감시로 종료됩니다. 다른 일반 게임 키는 차단하지 않습니다. 학교 보안 프로그램이나 더 높은 권한의 앱이 개입하는 경우에는 별도 Windows 키오스크 정책이 필요할 수 있습니다.
- 시작 화면과 연결 중 화면, 연결 지연 안내 및 다시 불러오기 버튼을 추가했습니다. 캐시된 업로드 로고는 시작 화면에서도 사용하며, 대기/감사 화면 중앙에 현재 로고를 표시합니다. 처음 연결하는 PC는 로고를 내려받기 전 기본 서비스 이름을 표시합니다.
- 관리자 → 좌석 / PC에서 좌석 삭제, 교실 자리 배치, 목록 순서 변경을 제공합니다. 마우스/터치로 PC를 이동하거나 PC 선택 후 빈칸을 누를 수 있습니다. PC 위에 놓으면 서로 위치를 바꿉니다. 목록은 드래그 또는 ↑↓ 버튼으로 순서를 바꿉니다. ‘배치 · 순서 저장’을 눌러야 다른 관리자·키오스크에 반영됩니다. 24×24칸까지 지원합니다.
- 배정/이용 중인 좌석은 먼저 이용을 종료해야 삭제할 수 있습니다. 삭제하면 PC 토큰과 발급된 등록 코드가 무효화됩니다. 해당 Station은 새 등록 화면으로 돌아가며 이전 이용/주문 기록은 보존됩니다. 다시 사용하려면 새 좌석을 만들고 등록 코드를 발급하세요.
- 관리자 Windows 전원 버튼을 재부팅으로 바꿨습니다. 기존 `pc.shutdown` 권한을 재사용하므로 권한을 다시 설정할 필요 없습니다. 구버전 종료 명령은 새 Station이 실행하지 않습니다. **모든 Station을 업데이트한 뒤 재부팅을 사용하세요.** PC의 명령 접수는 실제 재부팅 완료를 보장하지 않습니다.
- 상품/게임 추가·수정에서 PNG/JPG/WebP(최대 2MB) 이미지를 선택하고 저장할 수 있습니다. 상품은 상품 관리 권한, 게임은 게임 관리 권한이 필요합니다. 선택한 이미지가 등록 화면에 미리 표시되고, 저장하면 클라우드에 업로드됩니다. 이미지는 공개 저장소에 표시되므로 학생 인적사항이나 비공개 문서를 업로드하지 마세요. 이미지 제거는 항목의 연결을 해제하며 저장 파일 자체를 자동 삭제하지 않습니다.
- 좌석 추가 폼의 줄바꿈과 간격을 수정하고 기본 테마를 다크로 변경했습니다.

추가 전체 테스트는 요청에 따라 실행하지 않습니다. 타입 검사·앱 빌드·Windows 패키징 결과를 확인하며, 실제 Windows 노트북에서 종료/키 보호/게임 호환성 및 사용자 프로젝트 SQL 실행은 별도 확인이 필요합니다.

개발 빌드의 Windows 키 보호 실행 파일은 GitHub Actions의 MSVC 단계에서 `native/keyguard.cpp`를 컴파일해 생성합니다. `npm run build`만 실행한 Linux 개발 환경에서는 네이티브 보조 EXE가 생성되지 않습니다.
