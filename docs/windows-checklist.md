# 행사 전 Windows 실기 점검

현재 상태: **아래 Windows 항목은 이 Linux 클라우드에서 실행하지 않았습니다.** 행사에 사용할 실제 노트북과 게임으로 확인한 뒤 체크하세요.

## 설치·첫 설정

- [ ] Windows 10/11 x64에서 Server/Station 설치 마법사가 완료되고 바탕화면 바로가기가 생성된다.
- [ ] Node.js 없는 PC에서 서버가 실행되고 첫 비밀번호를 설정할 수 있다.
- [ ] 방화벽의 개인 네트워크 허용 후 다른 노트북에서 서버에 연결된다.
- [ ] 연결 파일을 불러오고 PC 등록 코드를 한 번만 사용해 등록한다.
- [ ] 비상 코드를 운영자가 보관하고 앱 재시작 후 등록 상태가 유지된다(DPAPI).
- [ ] 관리자 비밀번호 초기화 시 회계와 좌석 데이터는 유지된다.
- [ ] 업데이트와 제거가 정상 동작하고 사용자 데이터는 보존된다.

## 이용·결제

- [ ] 좌석 동시 선택 시 한 명만 발급된다. PC 로그인 전에는 시간을 차감하지 않는다.
- [ ] 다른 좌석이나 이미 사용한 로그인 번호로 입장하지 못한다.
- [ ] 간식 주문 시 머니·재고가 한 번만 차감되고 관리자에게 PC 번호와 함께 표시된다.
- [ ] 전달·취소·환불과 시간 연장이 정확히 반영된다.
- [ ] 수동 시간·머니 추가·차감, 잔액 부족·품절·시간 만료가 올바르게 표시된다.

## 게임별로 반복

- [ ] 등록한 경로에서 실제 게임이 실행된다.
- [ ] 게임 포커스 상태에서 오른쪽 위 마우스 1초 대기로 메뉴가 표시된다.
- [ ] 메뉴를 닫으면 게임을 계속 조작할 수 있다.
- [ ] 다른 게임 전환 시 기존 게임과 자식 프로세스가 종료된다.
- [ ] 게임이 먼저 종료되거나 시작에 실패해도 런처가 복구된다.
- [ ] 시간 만료와 관리자 이용 종료 시 게임을 닫고 로그인 화면을 표시한다.
- [ ] 다중 모니터·배율 125%/150%에서 모서리 감지와 메뉴 위치가 맞는다.

## 종료·장애

- [ ] Alt+F4가 앱을 바로 종료하지 않고 관리자 승인 메뉴를 연다.
- [ ] 현장 비밀번호와 원격 승인 각각으로 종료할 수 있다.
- [ ] 거절·만료·이전 승인 재전송으로 종료되지 않는다.
- [ ] 연결 단절 후 구매·연장·로그인이 막히고 기존 이용 시간은 계속 흐른다.
- [ ] 연결 단절 후 비상 코드로 종료할 수 있고 5회 오입력 제한이 재시작 후 유지된다.
- [ ] 서버 재시작 후 세션·주문을 복원하고 완료된 종료 명령을 다시 실행하지 않는다.
- [ ] Windows 종료 명령이 해당 PC에만 전달되며 접수/실패/만료가 구분된다.
- [ ] 서버 키오스크 창에 관리자 쿠키·데스크톱 제어 bridge가 없다.
- [ ] 행사 종료 개인정보 삭제 후 종료된 학생의 이름·학번이 보이지 않는다.
