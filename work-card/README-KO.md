# 작품 안내지 양식 (A4)

학생에게 **`PC-CLUB-작품안내-양식.html`** 하나만 나눠 주세요. 폰트가 파일 안에 들어 있어서 인터넷 없이도 열려요.

1. 크롬/엣지로 파일을 열고 안내지의 글자를 **클릭해서 바로 고칩니다** (한글 워드처럼). 조작방법·코인 줄은 `+ 추가` 또는 Enter로 늘리고, 빈 줄에서 Backspace로 지워요.
   **게임 화면 사진은 필수**예요. 사진 칸을 클릭하거나 파일을 끌어다 놓으세요. 사진이 없으면 저장 버튼이 막히고, Ctrl+P로 저장해도 PDF에 "사진 미첨부"가 찍혀요.
2. `PDF로 저장` → 대상 **PDF로 저장**, 용지 **A4**, 여백 **없음**, **배경 그래픽** 체크.
3. 파일 이름은 `학번이름_작품명.pdf`로 자동으로 정해집니다. 드라이브에 업로드하면 끝.

- 다크(축제) / 화이트(잉크 절약) 색상 선택 가능. 빈 칸 안내 문구와 빈 줄은 PDF에 나오지 않아요.
- 글이 길면 글자 크기가 자동으로 줄어들고, 그래도 넘치면 경고가 뜹니다.
- 입력 내용은 그 브라우저에 자동 저장됩니다.

양식을 고칠 때는 `template.html`을 수정한 뒤 `node scripts/build-work-card.mjs`로 배포 파일을 다시 만드세요.
